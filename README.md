# PsychoTest Pro

## Описание

**PsychoTest Pro** — это учебное приложение на Python (streamlit), предназначенное для проведения психологических тестов, анализа результатов и работы с тематическими материалами. Проект разрабатывается в образовательных целях.

## Структура проекта

- `src/`
    - `assets/` — папка с рисунками.
    - `main.py` — основной файл приложения, с которого начинается запуск программы.
    - `config.py` — конфигурационные параметры и настройки приложения.
    - `menu.py` — реализация меню и навигации по функциям приложения.
    - `results.py` — обработка, анализ и сохранение результатов тестов.
    - `runner.py` — управление запуском различных модулей и тестовых сценариев.
    - `tests.py` — модуль для тестирования и проверки функциональности приложения.
    - `themes.py` — содержит тематические материалы и вопросы для проведения психологических тестов.


## Назначение

Проект предназначен для студентов и преподавателей, изучающих психологию и методы тестирования, а также для всех, кто интересуется автоматизацией психологических опросов и анализом полученных данных.

## Содержание
- `Делегирование полномочий и принятие решений`
    - Тест на делегирование
    - Стили принятия решений
    - Самооценка делегирования
- `Развитие персонала`
    - Социализация и профессиональная идентичность
    - Практики профессионального развития
    - Зрелость системы обучения и повышения квалификации
- `Создание эффективной команды`
    - Сплочённость и доверие в команде
    - Качество коммуникации в команде
    - Роли, ответственность и вклад в команду
- `Мотивация персонала`
    - Тест на личную мотивацию в работе
    - Тест на систему мотивации и стиль управления
    - Склонность к отклоняющемуся поведению (А.Н. Орел)
- `Отбор персонала`
    - Системность и принципы отбора персонала
    - Навыки скрининга резюме и анкет
    - Качество интервью при отборе персонала
- `Управление проблемными сотрудниками`
    - Управляю ли я причинами проблемного поведения?
    - Как я провожу сложные разговоры с проблемными сотрудниками
    - Дисциплина и справедливость в работе с проблемными сотрудниками
- `Адаптация сотрудников`
    - Диагностика скорости адаптации
    - Оценка удовлетворенности процессом онбординга
    - Тест на интеграцию в команду
